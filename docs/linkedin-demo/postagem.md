I turned file transfers into a conversation.

With Drive Transfer Agent, I can select Google Drive folders, review a transfer plan, check available space, approve the copy, and track progress to my PC or MEGA—all through chat.

Built with React, FastAPI, Google ADK, OpenAI, and rclone.

This 45-second demo uses fictional data and simulated responses and progress. MEGA verification compares file sizes; it does not prove byte-for-byte equality. The interface is localized into English for this demo.
